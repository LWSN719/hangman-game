# Halo Hangman

A Halo-themed hangman game that runs in the browser.

- Easy (6 shields, shorter words, 100 pts) and Hard (4 shields, longer words, 200 pts)
- 3 hints per run (carry across missions), -25 pts each
- Fun fact after every completed word
- Animated Halo backdrop with clickable easter eggs

## Run locally

```
python3 -m http.server 8000
```

Then open http://localhost:8000. Fonts load from Google Fonts (Orbitron).
